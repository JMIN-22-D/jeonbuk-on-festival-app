# 전북 ON 축제 앱

전북사랑서포터즈 1기 **전북 ON** · 9~12월 전북 축제와 전북사랑도민증 할인가맹점을 휴대폰 앱 형식으로 보는 화면이에요.
웹사이트 버전은 [jeonbuk-on-festival-map](https://github.com/JMIN-22-D/jeonbuk-on-festival-map) 저장소에 있어요.

- 공유 링크: https://claude.ai/artifact/D4jcnVAF31coiuYtrdom4H
- 탭: 홈 · 지도 · 일정 · 할인 · 도민증. 축제를 누르면 상세 화면(사진, 프로그램, 주변 할인가맹점, 카카오맵 길찾기)이 열려요.
- 주소 끝에 `#map`(지도) `#cal`(일정) `#shop`(할인) `#card`(도민증)을 붙이면 그 탭으로 바로 열려요.
- PC에서는 휴대폰 틀(상태 표시줄 포함) 안에 보이고, 휴대폰에서는 화면 가득 앱처럼 보여요.

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 화면 |
| `data/festivals.js` | 축제 47개 일정·장소·프로그램·사진 출처 |
| `data/merchants.js` | 도민증 할인가맹점 506곳 |
| `data/geo.js` | 전북 14개 시군 경계 |
| `lib/common.js` | 날짜·거리·카카오맵 링크 등 공용 도우미 |
| `img/` | 축제 사진 47장 (위키미디어 공용, 출처는 `data/festivals.js`) |

## 보는 방법

`index.html`을 브라우저로 열면 돼요. 휴대폰으로 보려면 이 폴더에서 아무 정적 서버나 띄우세요 (예: `npx serve .`).

## 자료 고치기

`data/`, `lib/`, `img/`는 웹사이트 저장소와 같은 파일이에요. 축제나 가맹점을 고칠 때는 웹사이트 저장소에서 고친 뒤 이 세 폴더를 그대로 복사해 오세요. 자료 확인 방법과 출처는 웹사이트 저장소의 README에 정리돼 있어요.
